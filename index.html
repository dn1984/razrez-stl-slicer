Разрез STL → части

Режет модель на части с замками, которые держат склейку.

Открыть STL или перетащите файл в окно
Ось плоскости
1 Режется только окно по центру плоскости. Всё за ним остаётся целым — удобно отпилить крыло, не задев хвост.
↔ Оси окна: —
! Окно охватывает всё сечение по выбранной оси. Уменьшите ширину или высоту, чтобы оставить часть детали целой.
▭ Границы окна: —
Профиль
Плоский срез: две ровные поверхности, проще всего печатать.
Изгиб
Расставляются автоматически вдали от краёв. Shift + клик по срезу — добавить штифт вручную.
2 Второй рез выполняется после первого: сначала по Z, потом по X. Так деталь делится на четыре части.
Ось второго реза
▭ Границы окна: —

ЛКМ — вращать, колесо — масштаб, ПКМ — сдвинуть.

Части —

Разнесите их для проверки и сохраните каждую отдельно.
